## OpenGL Projects - Cross-Platform OpenGL ES 3.0 / WebGL Demo

A collection of real-time graphics and interactive simulation projects built in C++ targeting Desktop, Android, and the Browser.
<br><br>Play it here:
<br>Project 1: https://a-abellera.github.io/Android-Assignments/Assignment-1/
<br>Project 2: https://a-abellera.github.io/Android-Assignments/Assignment-2/
<br>Project 3: https://a-abellera.github.io/Android-Assignments/Assignment-3/

## Highlights
1. Multi-Platform Pipeline: One C++ codebase compiled for PC, Android, and Web (Emscripten)
2. Interactive 3D Scene: Oscillating and rotating fan motion with real-time shading and interactive controls
3. Asset & Shader Loading: Loads GLSL shaders and scene data across native filesystems, Android 'AAssetManager', and the WebAssembly virtual filesystem

## Controls
Project 1:
<br>Not interactable

Project 2:
1. Click: Toggles fan rotation
2. Drag: Increases fan speed

Project 3:
1. Left Buttons (Green): Increases/decreases fan speed
2. Right Buttons (Blue): Zooms in/out of scene
3. Click: Highlights sections of the fan
